Unit 1. Introduction to MIS

High yield. Unit 1 was Q1 in every paper: a definition, data vs information, and the role of IT.

1.1 MIS in one line

MIS (Davis and Olson) is an integrated user–machine system that provides information to support operations, management and decision-making, using hardware, software, manual procedures, models and a database. Keep the bold words; each one earns marks.

Why it matters: facts instead of intuition, better coordination across levels, faster decisions, and data turned into a competitive resource.

Five functions of MIS
Captureraw data→Processclassify, calculate→Storedatabase→Retrieveon demand→Disseminatereports

1.2 Data vs information

BasisDataInformation
NatureRaw, unorganised factsProcessed, meaningful
UseNot directly usefulBasis of decisions
ExampleInvoice lines, attendance punchesMonthly regional sales report, average attendance %
DIKW ladder: each step adds meaning
Wisdom: why, and what next

Information supports decisions in four steps: identify problems, evaluate alternatives, decide, monitor and control. Close an answer with: “without this, decisions fall back on intuition.”

1.3 System and information system

A system: input, process, output, feedback
Input→Process→Output
↺ Feedback and control sends results back to adjust the input
  • Elements: components, interrelationship, boundary, environment, input, process, output, feedback.
  • Types: open/closed, deterministic/probabilistic, physical/abstract, adaptive/non-adaptive.
  • Information system (Laudon): components that collect, process, store and distribute information. It is socio-technical: technology plus people plus organisation.
Six componentsRole
PeopleEnd users and IS specialists
HardwareComputers, storage, devices
SoftwareSystem and application programs
DataFacts held in databases
NetworkLinks hardware, shares resources
ProceduresRules for running the system

1.4 Business process design

A business process is a set of related tasks that produces a business outcome (order fulfilment, loan approval). Process design redesigns it, usually with IT, to cut cost and time and raise quality.

Hospital registration: as-is to to-be
As-ispaper form, queue at each counter, re-entry of data→Redesignmap, find waste, automate→To-bedata entered once, digital token, billing linked

1.5 Role of IT, retail, and adoption factors

  • Role of IT: automation, communication, better decisions, customer service (CRM), innovation.
  • Retail: POS, inventory systems, loyalty/CRM, e-commerce, supply chain visibility. End with: efficiency plus differentiation.
Adoption factors (TOE)Examples
TechnologicalInfrastructure, compatibility, security, cost
OrganisationalSize, top-management support, skills, culture
EnvironmentalCompetition, customers, regulation
EconomicROI, access to finance
Remember: IT = the technology. IS = IT + people + data + procedures, built to meet goals. Common mistake: calling MIS only a computer system.

3.4 PowerPoint, Access, Outlook

  • Outlook: email, calendar, contacts, tasks.

4.5 IT foundation and managerial challenges

  • IT foundation: hardware, operating systems, enterprise software, data management, networks, internet platforms, consulting and integration. It must keep being upgraded.

4.6 DBMS

Old file systems caused redundancy, inconsistency, program–data dependence and weak sharing. A DBMS sits between programs and data files and centralises data. Features: data definition, data dictionary, DML (SQL), integrity, concurrent access, backup, security.

Likely questions and answers

Tap a question to open the answer.

Define MIS and state two objectives. (Unit 1)

MIS is an integrated user–machine system that supplies information for operations, management and decisions, using hardware, software, procedures, models and a database. Objectives: support timely, accurate decisions; improve efficiency and coordination across departments.

Differentiate data and information. (Unit 1)

Data are raw facts; information is data processed into a meaningful form. Data alone cannot guide a decision; information can. Example: daily invoice lines are data, a monthly regional sales report is information. Close with: without this step, decisions rest on intuition.

How do TPS, MIS, DSS and ESS differ? (Unit 2)

Use the comparison table: TPS records routine transactions at the operational level; MIS summarises them for middle managers; DSS gives what-if analysis for semi-structured decisions; ESS gives dashboards to top managers for unstructured strategic decisions.

Challenges of enterprise systems / ERP? (Units 2, 5)

High cost, long and complex implementation, process reengineering, data migration, risk of misfit with unique processes, user resistance, vendor dependency. Add the strategic-alignment point.

Steps of mail merge. (Unit 3)

Prepare the main document and data source; Mailings → Start Mail Merge → Letters; Select Recipients → Use an Existing List; Insert Merge Fields; Preview Results; Finish and Merge → Print or Edit Individual Documents.

Explain VLOOKUP. (Unit 3)

=VLOOKUP(lookup_value, table_array, col_index_num, [range_lookup]) searches the first column of the table and returns a value from the stated column in the same row. FALSE gives an exact match.

Compare the five forces and value chain models. (Unit 4)

Five forces looks outward at the industry and shows threats; the value chain looks inward at activities and shows where IS adds value. Name the five forces and the primary and support activities.

RDBMS vs NoSQL. (Unit 4)

RDBMS: fixed tables, SQL, strong relationships, vertical scaling, suited to transactions. NoSQL: flexible schema, varied queries, horizontal scaling, suited to big and unstructured data.

Expert system vs DSS. (Units 2, 5)

An expert system uses an expert’s rules and an inference engine in a narrow domain and gives a recommendation; a DSS uses data and models, and the manager decides.

Quiz

Q1. Which system is the main source of data for MIS, DSS and ESS?
(a) ESS (b) TPS (c) KWS (d) Expert system

Answer: (b) TPS.

Q2. “Non-volatile” in a data warehouse means:
(a) Data is loaded periodically and then read-only (b) Data changes in real time (c) Data is deleted daily (d) Only current data

Answer: (a).

Q3. In VLOOKUP, FALSE as the last argument gives:
(a) Approximate match (b) Exact match (c) Error always (d) Sorted output

Answer: (b) Exact match.

Q4. Unstructured decisions are mainly supported by:
(a) TPS (b) MIS (c) ESS (d) OAS

Answer: (c) ESS.

Q5. Which is NOT one of the six components of an information system?
(a) People (b) Procedures (c) Network (d) Competitors

Answer: (d) Competitors.

Q6. OLX is an example of:
(a) B2C (b) B2B (c) C2C (d) C2B

Answer: (c) C2C.

Q7. The flow “TPS → warehouse → mining → ___” ends with:
(a) ERP (b) BI (c) SCM (d) DBMS

Answer: (b) Business intelligence.
